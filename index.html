The Process

From local machine to the web.

The entire project can be version controlled and deployed using GitHub.

~/devforge 
# Create your project
$ mkdir devforge
$ cd devforge

# Create the webpage
$ touch index.html

# Initialize Git
$ git init

# Save your work
$ git add .
$ git commit -m "Initial commit"

# Push to GitHub
$ git branch -M main
$ git remote add origin YOUR_REPOSITORY_URL
$ git push -u origin main

✓ Your code is now on GitHub.
Git Workflow

Four commands. Real version control.

A tiny workflow that teaches the foundation of professional source control.

01 / INIT

Initialize

Turn your project directory into a Git repository.

02 / ADD

Stage

Tell Git which changes should become part of the next snapshot.

03 / COMMIT

Commit

Create a permanent versioned snapshot with a meaningful message.

04 / PUSH

Publish

Push your commits to GitHub and make the project available online.
